# 3VisOff

Личный органайзер для 3D-визуализатора: клиенты, проекты, расчёт цены, финансы и налоги, календарь, договоры, счета и акты. Все данные хранятся только на вашем компьютере.

Скачать последнюю версию: [раздел Releases](https://github.com/AdeptVision3D/3VisOff-releases/releases/latest) (файлы лежат в блоке **Assets**).

Разработчик: Adept, Telegram [@cute_adept](https://t.me/cute_adept)

## Установка на Windows

1. Скачайте `3VisOff-Setup-….exe` из блока **Assets** последнего релиза и запустите.
2. Windows может показать предупреждение «Неизвестный издатель» (у программы пока нет цифровой подписи). Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**.
3. Обновления приходят сами: программа предложит обновиться, данные сохраняются.

## Установка на Mac

Программа пока без подписи Apple, поэтому при первой установке macOS предупреждает, что не знает разработчика. Это нормально: нужно один раз разрешить запуск. Данные хранятся только на вашем компьютере.

## Первая установка

1. Скачайте файл `3VisOff-…-arm64.dmg` из раздела **Assets** последнего релиза (подходит для Mac с чипами M1, M2, M3 и новее).
2. Откройте скачанный файл и перетащите **3VisOff** в папку **«Программы»**.
3. Закройте окно установщика и извлеките его (кнопка ⏏ рядом с ним в Finder).
4. Откройте **Терминал** (Spotlight: `⌘ Пробел`, напишите «Терминал», Enter), вставьте команду и нажмите Enter:

```bash
xattr -cr /Applications/3VisOff.app
```

   Она ничего не покажет, это нормально: так macOS снимает пометку «скачано из интернета».
5. Откройте 3VisOff из «Программ». Готово.

### Если не хочется использовать Терминал

1. Попробуйте открыть 3VisOff. macOS покажет предупреждение, нажмите «Готово».
2. Откройте **Системные настройки → Конфиденциальность и безопасность**, прокрутите вниз до сообщения про 3VisOff и нажмите **«Всё равно открыть»**. Подтвердите паролем или Touch ID.

## Обновления

- Когда выйдет новая версия, программа сама предложит обновиться. Нажмите «Обновить»: она скачает новую версию, перезапустится, и вручную ничего делать не нужно. Перед обновлением автоматически сохраняется резервная копия данных.
- Если автообновление недоступно (например, программа запущена не из папки «Программы»), откроется страница загрузки: скачайте `.dmg` и повторите шаги выше.
- Версии 0.7.0 и старше обновляются вручную. Автообновление работает, начиная с версии, где оно появилось.

## Если что-то пошло не так

Данные лежат в `~/Library/Application Support/3VisOff` и не удаляются при переустановке. Резервные копии — рядом, в папке `backups`.
